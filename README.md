# Nuit Rouge — landing page

Landing page de lancement conçue avec Next.js, React, Tailwind CSS, Motion, Three.js, DotLottie et Lucide.

## Démarrer

```bash
pnpm install
pnpm dev
```

La scène charge le modèle `public/parfum.glb`. La rotation du flacon suit la progression du scroll. La date d’annonce est réglée au 20 décembre 2026 dans `components/launch-experience.tsx`.
